## Reunión 1 — Inicialización del proyecto

**Fecha:** 03/04/2026  
**Tema:** Inicio y organización del proyecto

### Objetivos

- Presentar y analizar la propuesta del proyecto.
- Definir los objetivos principales del sistema.
- Distribuir las responsabilidades iniciales entre los integrantes.
- Establecer una forma de trabajo para el desarrollo.

### Relevamiento

Durante la reunión inicial se analizó la propuesta del proyecto y se establecieron los principales objetivos y funcionalidades que debía contemplar el sistema.

Se realizó una primera distribución de responsabilidades entre los integrantes, definiendo los principales enfoques de trabajo para frontend, backend y desarrollo general.

También se acordó utilizar un repositorio compartido mediante GitHub y establecer una organización inicial basada en ramas individuales para permitir el trabajo paralelo de los integrantes.

Como herramienta de seguimiento se planteó la utilización de Trello para registrar y organizar las tareas del proyecto.

### Resultado

Se estableció una estructura inicial de trabajo, se asignaron las primeras responsabilidades y se definieron los objetivos generales que servirían como base para comenzar el desarrollo.
