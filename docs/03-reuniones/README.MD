## Reuniones

A lo largo del desarrollo del proyecto se realizaron reuniones de seguimiento en momentos considerados relevantes dentro del proceso de desarrollo. Debido a la naturaleza académica del proyecto, estas reuniones no siguieron una periodicidad estricta, sino que fueron coordinadas de acuerdo con los principales avances, decisiones y necesidades que surgieron durante el desarrollo.

Hasta el momento se identifican tres reuniones principales. Una cuarta reunión se encuentra planificada para la etapa final del proyecto, donde se prevé abordar el despliegue, las verificaciones finales y la incorporación de pruebas automatizadas.
