#### Comparación de Librerías para: Generación Automática de Documentación

**Problema:** Necesitamos generar una documentación de referencia de la API de3 nuestro backend directamente desde el código fuente de TypeScript, para mantenerla siempre actualizada y facilitar la integración entre equipos.

| Criterio                       | [![Documentation Tool - TypeDoc](https://img.shields.io/badge/TypeDoc-%23007ACC?style=for-the-badge&logo=TypeDoc&logoColor=white)](https://typedoc.org) | [![Documentation Tool - JSDoc](https://img.shields.io/badge/JSDoc-F74E3B?style=for-the-badge&logo=JSDoc&logoColor=white)](https://jsdoc.app) | [![Documentation Tool - Docusaurus](https://img.shields.io/badge/Docusaurus-000000?style=for-the-badge&logo=docusaurus&logoColor=white)](https://docusaurus.io) |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Popularidad/Comunidad**      | Estándar de facto y muy popular en el ecosistema TypeScript.                                                                                            | El clásico de JavaScript. Comunidad masiva pero menos enfocada en TS.                                                                        | Muy popular para sitios de documentación completos (usado por React Native, Jest, etc.).                                                                        |
| **Curva de Aprendizaje**       | **Baja.** Diseñado para TypeScript. Funciona casi sin configuración si ya usas comentarios TSDoc.                                                       | **Baja.** La sintaxis de comentarios es simple, pero requiere plugins y configuración para funcionar bien con TS.                            | **Moderada.** Es un generador de sitios estáticos con React. Requiere aprender su ecosistema.                                                                   |
| **Rendimiento / Generación**   | Rápido. Genera un sitio HTML estático y limpio enfocado en la API.                                                                                      | Rápido. Similar a TypeDoc, genera sitios estáticos.                                                                                          | La generación es más lenta. Crea una Single-Page App (SPA) más pesada pero más interactiva.                                                                     |
| **"Boilerplate" / Verbosidad** | **Mínima.** A menudo basta con un solo comando en la CLI. Infiere todo desde los tipos de TS.                                                           | Moderada. Requiere más etiquetas explícitas en los comentarios para lograr lo que TypeDoc infiere.                                           | Alta. Necesita una estructura de proyecto, archivos de configuración, componentes React, etc.                                                                   |
| **Ecosistema / Flexibilidad**  | Bueno, con plugins para temas y formatos de salida (JSON, Markdown). Se enfoca en una sola cosa: docs de API.                                           | Enorme, con incontables plantillas y plugins debido a su antigüedad.                                                                         | **Excelente.** Altamente extensible para crear portales de documentación completos con blogs, guías y más.                                                      |
| **Veredicto Rápido**           | La opción nativa y directa para proyectos TypeScript. "Simplemente funciona".                                                                           | El veterano de JavaScript. Flexible, pero necesita adaptadores para brillar con TypeScript.                                                  | La mejor opción si necesitas un portal de documentación completo, no solo una referencia de API.                                                                |

---

**🏆 Decisión Final:** Se elige **TypeDoc**.

**Justificación Principal:** TypeDoc es la herramienta más eficiente y directa para resolver nuestro problema específico. Al estar construido para TypeScript, aprovecha al máximo nuestro código existente (tipos, interfaces, etc.) para generar una documentación precisa con un mínimo esfuerzo y configuración. Ofrece el camino con menor fricción para obtener una referencia de API útil y siempre actualizada.
