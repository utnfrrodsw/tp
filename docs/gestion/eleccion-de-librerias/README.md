# 📝 Elección de Librerías

La selección de nuestras herramientas y librerías no es arbitraria. Cada decisión se basa en un análisis comparativo que busca equilibrar factores clave como la **experiencia de desarrollador (DX)**, el **rendimiento**, el **tamaño del paquete final**, el **ecosistema** y, en el contexto de este proyecto, el **valor pedagógico** de cada tecnología.

En esta sección se documentan las comparativas realizadas y la justificación detrás de cada elección tecnológica fundamental, tanto para el Frontend como para el Backend.
